# EffectiveMobile

Этот API разрабатывался как тестовое задание на вакансию Go разработчика в EffectiveMobile.

В нём я реализовал все 4 метода:
1. Для получения данных с различными фильтрами и пагинацией /persons [get]
2. Для удаления по идентификатору /person [delete]
3. Для изменения сущности /person [patch]
4. Для добавления новых людей в формате /person [post]

Так же было реализовано обогащение с помощью сторонних API для получения Возраста, Пола и Национальности.
В качестве БД была использована PostgreSQL, запущенная через Docker. Все параметры запуска указаны в файле .env.

Все необходимые на мой взгляд места в коде были покрыты логами.

Для 6 пункта задания я реализовал генерацию Swagger. /swagger/*

Рефакторинг кода был произведён, оталкиваясь от project-layout

Подробное описание структуры:
  Папка cmd содержит основной файл main.go для запуска.
  Папка internal содержит 3 подпапки:
    Папка DB содержит инициализацию Базы Данных вместе с файлом .env
    Папка handlers содержит ручки
    Папка personService содержит 3 файла:
      Файл orm.go реализует структуры
      Файл repository.go реализует взаимодействие с БД
      Файл service.go реализует валидацию данных
